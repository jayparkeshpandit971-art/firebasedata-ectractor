# 🔥 Firebase Dumper Bot

Telegram bot that extracts Firebase data even with read:false rules.

## Deploy on Render

1. Fork this repo
2. Create Web Service on Render
3. Set Environment Variable: `BOT_TOKEN`
4. Set Webhook: `https://your-app.onrender.com/bot.php?set_webhook`

## Commands
- `/start` - Welcome
- `/help` - Instructions
- `/status` - Bot status
- `/bypass` - Show bypass methods
- `/test` - Test connection

## Bypass Methods
- Auth Override
- Rules Bypass
- Admin Impersonation
- Token Exchange
- Storage Extraction
